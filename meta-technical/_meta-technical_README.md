# meta-technical

This directory contains documents describing the deep-layer, substrate-level mechanics of the Rift Worlds ontology.  
These documents define the fundamental structures, constraints, and causal processes from which all higher-level phenomena emerge.

Contents typically include:
- distinction-space and substrate primitives  
- structured computation and deep-layer dynamics  
- Noesis Field behavior and architecture  
- etheric structures, ethereons, qualions  
- essence mechanics at the substrate level  
- metachemistry and hyperchemistry (deep-layer formulations)  
- ontological ordering and emergence rules  
- substrate-level constraints, invariants, and conservation laws  

These files establish the foundational mechanisms that higher-layer (phenomena-technical) documents must remain consistent with.
