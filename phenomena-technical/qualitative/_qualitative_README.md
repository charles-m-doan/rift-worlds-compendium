# qualitative

This directory contains qualitative descriptions of emergent phenomena in the Rift Worlds ontology.  
Documents here describe system behavior conceptually, experientially, or narratively, without requiring formal models or precise quantitative specifications.

Typical contents include:
- conceptual descriptions of magic and other emergent systems  
- broad-strokes causal or behavioral relationships between phenomena  
  (e.g., “force increases with acceleration” as a qualitative rule)  
- emergent essence behavior and interaction tendencies  
- Rift effects as observed within Tetra  
- narrative-level summaries of system behavior  
- rule-of-thumb descriptions of interactions or constraints  

Qualitative descriptions should reflect substrate logic indirectly but do not need to specify deep-layer mechanisms, equations, thresholds, or exact quantitative mappings.
